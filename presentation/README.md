# Project Presentation

This folder contains presentation materials summarising my research project, **Kenya’s Public Spending and Income Inequality**.

The presentation highlights the research problem, data sources, analytical approach, key findings, policy implications and study limitations. It provides a concise overview of the project and communicates its main insights in an accessible format.

## Contents

- **PDF Presentation:** A shareable version of the research presentation.
- **PowerPoint Presentation:** The editable presentation file.

These materials were prepared as a summary of the research project for the ALX Data for Impact Challenge.
